# Getting help

1. **Check the docs first:** the README section "When something does not work", [docs/FIRST_RUN.md](docs/FIRST_RUN.md)
   and [docs/HOW_TO_ASK.md](docs/HOW_TO_ASK.md). Ask your assistant to run the `wow_doctor` tool: it checks the dump
   file, versions and data age, and says what to do next.
2. **Questions, setup help, ideas:** start a thread in
   [Discussions](https://github.com/Piekario/wow-mcp/discussions).
3. **Something is broken:** open a [bug report](https://github.com/Piekario/wow-mcp/issues/new/choose) with the
   `wow_doctor` output, `/mcp status` from the game and your versions.
4. **Security problems:** never in public; see [SECURITY.md](SECURITY.md).

wow-mcp is maintained in spare time, so answers may take a few days. Help from other users in Discussions is very welcome.
